# مدار (Madar)

## متغيرات البيئة المطلوبة

أنشئ ملف `.env.local` في جذر المشروع بهذه المتغيرات:

```env
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

- `CLOUDINARY_API_KEY` — مفتاح API من Cloudinary Dashboard → Settings → API Keys
- `CLOUDINARY_API_SECRET` — السر المقابل للمفتاح
